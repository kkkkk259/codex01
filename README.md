# Todo Atelier

一个简洁、可直接本地运行的 Todo 网页应用，支持新增、修改、删除和列表展示，并通过浏览器 `localStorage` 自动保存任务数据。

## 项目预览

这是一个纯前端静态项目，不依赖框架和后端服务。打开 `index.html` 即可使用，适合拿来做练手项目、静态页面演示，或者继续扩展成更完整的任务管理应用。

## 功能说明

- 新增待办任务
- 行内修改任务内容
- 删除任务
- 勾选任务完成状态
- 实时展示任务列表
- 自动统计总任务、已完成和待处理数量
- 使用 `localStorage` 持久化保存数据，刷新页面后内容不会丢失

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript

## 使用方式

1. 进入项目目录
2. 直接双击打开 `index.html`

或者使用本地静态服务器打开，例如：

```powershell
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/index.html
```

## 文件结构

```text
.
├── index.html   # 页面结构
├── style.css    # 页面样式与响应式布局
├── script.js    # Todo 增删改查与本地存储逻辑
└── README.md    # 项目说明
```

## 页面组成

- 左侧信息区：展示项目标题、简介和任务统计
- 右侧操作区：包含新增任务表单和任务列表
- 列表项操作：支持完成、编辑、保存、删除

## 核心逻辑

项目核心逻辑集中在 `script.js`：

- 读取本地存储中的任务数据
- 渲染任务列表
- 处理新增任务提交
- 处理任务完成状态切换
- 处理任务编辑和保存
- 处理任务删除
- 更新顶部统计数字
